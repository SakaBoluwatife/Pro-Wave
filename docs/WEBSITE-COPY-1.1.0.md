# Ovrtone 1.1.0 — copy for the download page

Public release. Reuse as much or as little of this on the site as suits.

## Short hero line

Ovrtone 1.1.0 — a DAW for Windows with a Logic-style arrangement and mixer, FL Studio's piano roll and channel rack, spatial mixing, and 35 analog-hardware plugins in the box.

## One-liner

Bring your own VST3 and CLAP plugins and your own samples. Ovrtone is the host — Logic on one side, FL Studio on the other, spatial on top.

## What's in 1.1.0 (headline features)

- **BSL Classics, 35 analog-hardware plugins, in the box.** Compressors, EQs, preamps, consoles, tape machines, reverbs, echoes, modulation and saturators. VST3, Windows. An optional install component.
- **Tuner on the control bar.** A real-time pitch readout with a cents needle, plus a compact reading beside the button. Tuning reference is adjustable (A=432, 440, 442 or any value from 400 to 480 Hz).
- **Spatial.** Surround panner and renderer reworked: direction and elevation are independent, the room shows speakers in place of dots and lights them as objects come near, Size and Spread hide under More.
- **Mix templates.** Rap Vocal Mix, R&B Vocal Mix, and Beat + 2-Track in the Project Chooser, each with the usual vocal routing, a Vox Bus and the common returns (Short Verb, Long Verb, Slap, Throw Delay where it fits).
- **Browser extras.** A Presets tab lists every saved plugin preset, grouped by plugin; a Project Audio tab lists the audio files each track's regions use.
- **Piano Roll.** Preview on each drawn or moved note (toggle off any time), playing notes and keys light up, the pencil cursor is bigger and the tool shows at the mouse.
- **Channel Rack.** Steps sound when switched on, Delete Channel on right-click, the piano button opens the main Piano Roll (the small rack roll is gone).
- **MIDI recording with the cycle on** now jumps the playhead into the cycle before the count-in, so cycle recording captures the first bar.
- **Logic-style tool menu** (press T over the tracks to pick P Pencil, E Eraser, I Scissors, J Glue, M Mute, S Solo, Z Zoom, A Fade, R Marquee and more).
- **Middle C naming follows the program you came from** (C5 for FL Studio, C3 for Logic, Ableton, Pro Tools).
- **Sampler window overhaul** and **EQ slot** on channel strips.

## Full feature list (short form)

### Core
- VST3 and CLAP plugin hosting with crash isolation: a crashing plugin does not take the DAW down.
- WASAPI and ASIO audio (optional).
- Low Latency Mode, cycle, count-in, varispeed, metronome.
- 64-bit summing, PDC, per-track automation.

### Arrangement
- Tracks, folders, VCAs, aux returns.
- Audio comping with real crossfaded joins; named and coloured takes.
- Alt-drag copies; frozen tracks on the Playlist.

### MIDI
- Piano Roll with per-note pitch bend for slide notes (on instruments that take it).
- FL-style Channel Rack with a shared pattern across clips.
- Step Editor with velocity and chance lanes.

### Mixer
- Shared plugin and effect order on strips; EQ slot; plugin presets.
- Sends, groups, control surfaces (HUI, Mackie).

### Spatial
- Dolby-Atmos-style object mixing: 7.1.2 bed, per-track objects.
- Binaural render on headphones (SOFA files), speaker render for a monitoring room.
- ADM BW64 export.

### Export
- WAV, MP3, stems, "For Beat Store" one-shot export.
- AAF import for other DAWs' sessions.

## Install

- Windows 10 or later, 64-bit.
- Full installation includes Ovrtone, the Stem Splitter model, documents and the BSL Classics plugins.
- Compact installation is the program only (~55 MB).

## Known gaps (documented, not hidden)

- No stock instruments, effects or sound library — by design. Bring your own plugins.
- No Mac or Linux build yet.
- MP4 video export of the visualiser comes later (needs the dedicated video engine).
